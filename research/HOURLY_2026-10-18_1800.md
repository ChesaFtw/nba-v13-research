# V13 18:00 CT audit — venue-conditioned pace (research only)

Source: previously recovered 4,947 retrospective NBA team-game boxes (2022–26); 4,910 valid after existing quality gate. Estimated possessions are FGA + 0.44*FTA - OREB + TOV, **not independently observed**. No sportsbook lines, live injuries, or lineups.

Frozen comparison: baseline = mean of both teams' last 10 regulation-game pace proxies; challenger = 50% baseline + 50% mean of home team's last five home and away team's last five away pace proxies. Same-date batches prevent leakage; regulation games only, Jan 15 onward. No parameter search. The separate existing `possession_matchup_gate_1800.py` is not this experiment.

Previously examined 2024–25/2025–26 evaluation (n=1,218): estimated-possession MAE **3.434576 baseline vs 3.458642 challenger** (improvement −0.024066, date-bootstrap 95% CI [−0.049449,+0.001315]). PPP × pace game-total MAE **14.466009 vs 14.470347** (improvement −0.004337, CI [−0.068874,+0.056827]). All four individual seasons worsened possession MAE; pooled n=2,376 improvement −0.021123. No validated gain. This total baseline is PPP × baseline pace, not the existing scored/allowed-points baseline.

Local: 10 experiment tests + 18 isolated tests for the already committed pace helper; combined selected suite 123 passed, 0 failed. Local reproducibility package includes frozen protocol, code, historical data, results and checksums. An attempt to upload the helper tests was blocked; the code is not on this branch. Do not treat existing CI as validation of this experiment.

Research decision: reject venue-conditioned pace blend; preserve existing V13 baseline. Injury/lineup snapshots, independently observed possessions, verified pretip odds, and confidence calibration remain blockers. No promotion, activation, staking changes, bets, or merge to main.
