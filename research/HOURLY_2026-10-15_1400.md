## Primary finding: incremental return-gap feature fails
Matched chronological Ridge(alpha=25) on the same played-player rows, comparing existing contextual minutes features against those features plus team-game gap, gap>=3 and team-history indicator. Training always predates the test window. The same 2025–26 season and test windows have already been examined; this is exploratory, not independent validation.

For returners with >=3 missed team games: Jan n=175 gain +0.00564 (95% game-cluster CI [-0.02311,+0.03176]); Feb n=139 gain -0.12978 (CI [-0.20309,-0.05511]); March n=241 gain -0.02044 (CI [-0.04596,+0.00962]). A separate validation-only negative residual adjustment selected zero in all three windows. **Do not promote this gap feature.** Earlier large improvements versus last-10 rolling minutes did not translate into incremental value beyond the contextual minutes Ridge model.
